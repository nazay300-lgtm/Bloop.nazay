# Bloop 1.0.0 Beta

## Что вошло в бету
- Чаты, контакты и группы.
- Индивидуальные и групповые звонки, видеопоток и демонстрация экрана реализованы на WebRTC; требуется проверка на реальных устройствах и сетях.
- Автоматическое обнаружение пользователей в локальной сети.
- Добавлен раздел «Настройки → Обновления» с горизонтальным списком релизов и описанием выбранной версии.
- Подключена интеграция `electron-updater`; сборка переведена на NSIS installer.
- Добавлена инструкция по настройке GitHub Releases и выпуску автоматических обновлений.

## Ограничения этой беты
- Для публикации обновлений нужно указать владельца/имя репозитория GitHub и настроить токен публикации.
- Реальный обмен звонками между двумя физическими устройствами не подтверждён автоматическими проверками.
- Для части интернет-соединений может понадобиться TURN-сервер; STUN не обходит все варианты NAT.
