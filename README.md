# Bloop: локальный P2P-мессенджер



Bloop — мессенджер для геймеров и пользователей, которым важны быстрая связь и низкая задержка. Использует локальную сеть для обнаружения пользователей и обмена данными без обязательного центрального сервера для каждого соединения.

**Преимущества LAN-соединения:**
- Низкая задержка при хороших сетевых условиях.
- Быстрая передача данных внутри локальной сети.
- Меньшая зависимость от внешнего интернета.
- Потенциально меньше промежуточных серверов.
- Удобно для общения в одной сети.

 скачайте и установите приложение, запустите Bloop и задайте никнейм. Пользователи в поддерживаемой локальной сети могут обнаруживать друг друга и начинать общение.

*Доступность звонков и обнаружения зависит от текущей реализации, настроек сети и брандмауэра.*
