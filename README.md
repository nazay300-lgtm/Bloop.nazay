# Bloop: локальный P2P-мессенджер

## Начало общения без комнат
1. Запустите Bloop на обоих компьютерах и завершите настройку профилей.
2. Подключите устройства к одной локальной сети или VPN-сети, разрешающей связь между клиентами.
3. Откройте **Настройки → Друзья → Найти друзей в сети**.
4. Найдите человека по нику и нажмите **Добавить**. Друг принимает запрос, после чего контакт сохраняется.
5. При следующем обнаружении сохранённого друга приложение автоматически пытается восстановить соединение.
6. Откройте контакт и начните переписку или личный звонок. Для группового звонка создайте обычную группу контактов и используйте кнопку группового звонка в этой группе.

Создание комнаты для установления связи больше не требуется. Приложение запускает локальную сигнализацию автоматически.

## Архитектура сети
- **Обнаружение LAN:** UDP broadcast на порту `45888`. В объявлении передаются ник и френд-код. Список найденных устройств локальный и устаревает после 15 секунд без объявлений.
- **Сигнализация:** каждый экземпляр Bloop запускает встроенный WebSocket listener на TCP-порту `8080`. Это локальный компонент приложения, не внешний центральный сервер. Для связи устройств через LAN/VPN оба приложения должны быть доступны друг другу на этом порту.
- **Сообщения и файлы:** передаются между подключёнными устройствами через WebRTC DataChannel.
- **Аудио/видео:** WebRTC соединяет участников напрямую, когда сеть позволяет. Групповые звонки используют mesh-схему: каждый участник соединяется напрямую с другими участниками. Это подходит для небольших групп, но нагрузка растёт с числом участников.
- **STUN:** настроен публичный STUN для попыток прямого соединения вне LAN. STUN не ретранслирует медиа и не гарантирует прохождение любого NAT.
- **TURN:** не настроен. Для некоторых сетей без общей LAN/VPN соединение через интернет не установится без ретранслятора. Проект не обещает универсальную связь через любой NAT без инфраструктуры.

## Сетевые требования
- UDP `45888` для обнаружения устройств.
- TCP `8080` для встроенной сигнализации.
- Разрешите Bloop в брандмауэре Windows для частных сетей.
- Некоторые гостевые Wi-Fi и VPN запрещают broadcast или изолируют клиентов. В таких сетях автоматический поиск может не работать. В диалоге поиска оставлен ручной резервный способ подключения по IP и френд-коду.

**Важно:** сетевые звонки не считаются полностью подтверждёнными только на основании статических проверок. Перед раздачей беты проверьте звонки на двух реальных устройствах, включая микрофон, камеру, демонстрацию экрана и повторное подключение. Для некоторых интернет-соединений нужен TURN-сервер.
